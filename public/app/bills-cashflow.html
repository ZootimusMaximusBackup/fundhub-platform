Bills & Cash Flow

no client

Recurring bills detected from the account history, and the day-by-day cash projection built on them.

Nothing on this page reads a bank. Every charge behind these bills was entered into this system by hand. Run detection reads the transactions already stored and works out which ones repeat — it does not fetch, sync or refresh anything, so if the history stops three weeks ago, so does the answer. A detected bill is an inference, not a statement. Each one shows how sure the detector is and how many charges it is based on, and you can open the actual charges behind any of them.
