Subscriptions

no client

The plan this client is on, the price, and the card on file for it.

Nothing on this page charges anybody. Starting, changing or cancelling a plan here writes down what the client is on. There is no card processor connected to this system, so no money moves and no invoice is raised. A card below is a reference to a card held by a processor — a token, plus the brand, last four digits and expiry so a person can tell one card from another. The card number itself is not here, is not asked for, and is refused if it is sent.

A Commas checkout link for one amount — a deposit, the diagnostic fee, a repair charge, or anything else. Unlike the plan above, this DOES move money: the client pays Commas directly, and this screen only records the ask and, once Commas tells us, the result.
