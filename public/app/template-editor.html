    How this works

    Editing the words switches the message off. The system will not send a message whose wording has not been approved. So when you change the copy here and save it, that message stops going out straight away.

    An owner or admin turns it back on. They have to read the new wording on this screen first — there is no way to approve from the list without opening it. Who approved it and when is recorded on the message.

    The short name cannot be changed, and nothing can be deleted here. Automations and journeys find a message by its short name. Change it and the message quietly stops going out with nothing reporting a problem. Each message shows what is using it.

    Nothing on this screen sends anything. There is no test-send button because nothing transmits yet.
