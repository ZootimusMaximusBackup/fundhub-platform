# CRM feel — 2026-08-17

Owner report: the CRM feels janky. Five things, all believed shared-stylesheet level.

1. Clicking around causes loading and glitching. Panels jump.
2. It zooms in and out slightly — inconsistent scaling.
3. When zoomed out the layout doesn't scale. Panel edges show as visible seams
   instead of one surface. Owner works zoomed out.
4. The font is small.
5. Overall it feels barely hanging together, not like expensive software.

Owner instruction: measure on the live site first. Find the real causes. Do not
assume the owner's list is complete. Fix in the shared stylesheet where possible,
not screen by screen. Standing GO. No invented data.
