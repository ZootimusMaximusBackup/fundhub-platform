## Live prove — Workspace admin (Chris)

Before production booking works against real calendars:

1. Open [Google Workspace Admin → Security → API controls → Domain-wide delegation](https://admin.google.com/ac/owl/domainwidedelegation)
2. Edit the existing Company Brain service account client ID (same one as Drive)
3. Add scope: `https://www.googleapis.com/auth/calendar.readonly`
4. Save — no new env vars needed (`GOOGLE_DRIVE_SERVICE_ACCOUNT_JSON` already set on Netlify)

**Prove:** book a 1:1 on a host who has a conflicting Google Calendar event → expect `HOST_BUSY` with calendar detail, not a saved interview.
