## Why no `-actual.md` file changed

Four independent checks, each run against the tree as it now stands:

1. **These files are machine-generated, not hand-written.** Every one carries
   `<!-- GENERATED by scripts/journeys/generate.mjs — do not edit by hand. Run
   npm run journeys. -->`. `scripts/journeys/generate.mjs --check` compares the
   committed bytes against what the code produces and exits 1 on any difference,
   and `npm test` runs it. **A hand edit here does not document the change — it
   breaks the suite.**

2. **The generator never reads a screen.** `scripts/journeys/extract.mjs` reads
   the `ROUTES` map in `netlify/functions/api.mjs`, `src/http/read-api.mjs`,
   `src/http/partner-read-api.mjs`, `src/http/dashboard-auth.mjs` and the gate at
   the top of each `api/*.mjs` handler. It reads nothing under `public/app/`.
   A screen edit cannot move these pages.

3. **The screen calls exactly the same endpoints before and after.** Measured by
   diffing every `/api/...` string in `git show HEAD:public/app/creative-factory.html`
   against the working tree. Both sides are the same eight endpoints:

   ```
   /api/creative/actions   /api/creative/approvals  /api/creative/brand-kits
   /api/creative/generate  /api/creative/jobs       /api/creative/library
   /api/creative/run       /api/partner-marketing/usage
   ```

   (Two further matches, `/api/dashboard/` and `/api/read/`, are on both sides and
   are prose inside a JavaScript comment at `:1945`, not calls.)

4. **The check agrees.** `npm run journeys:check` →
   `docs/journeys is up to date (9 files).` Programmatic re-run of
   `generate.build()` + `generate.stale()` → **stale count 0**.

This matches the precedent already at the top of `CHANGELOG.md`: the
contracts-dedup batch earlier today recorded the same outcome in the same words
— journeys track routes and gates, not screen layout.
