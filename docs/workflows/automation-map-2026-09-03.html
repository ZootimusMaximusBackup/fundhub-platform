FundHub Automation Map

What the system is supposed to do on its own at every point of the customer journey, read out of the code on 2026-09-03. Every box names the file that does it, the event that fires it, the exact email or text it sends, and how long it waits. This is the answer key for the walkthrough.

Source of truth: src/workflows/index.mjs (68 registered automations) plus the sync handlers in src/handlers/. "Registered" means the code will run it. Whether it actually fires on the live site is what the walk measures. Three things are marked retired or placeholder because the code says so.

Rounded = the customer or staff does itBox = automation (file name)Hexagon = message sent, by template keyDiamond = gate or decisionDouble box = known gapDotted arrow = happens after a wait
