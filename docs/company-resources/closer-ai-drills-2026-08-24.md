## Scenarios (all products)

### D1 — $32 file read

Buyer typed a score, said they have negatives, cash is unclear.  
**Right lane:** soft pull **$32**, cash.  
**Must:** not a bank app; pay + consent before any pull; not the $3,000 start.  
**Fail:** “this will not affect you at all” as a blanket; “once we pull you’re approved.”

### D2 — Funding DFY, normal start

Buyer about **700+**, can pay cash now. Wants us to do the work.  
**Right lane:** funding start (good start **$3,000**, can go up or down) + **10%** later **if** a lender funds them. Cash. Not Commas.  
**Must:** deposit is **part of** the 10%. No business required. Lenders decide.  
**Fail:** sure fund; set bank dollar; Alec $8–10k.

### D3 — Funding start moves

Same as D2, but they cannot do $3,000 today and they are still a cash funding buyer.  
**Right lane:** closer may go **lower** (or up if the deal supports it). Still cash. Still part of the 10%.  
**Must:** write the real dollar; ask a manager if they do not know how to set the pay link.  
**Fail:** fake payment plan for the deposit; put the start on Commas.

### D4 — Funding + repair

Buyer about **700+**, cash for about **$4,000** ($3,000 + $1,000), file looks like it needs work.  
**Right lane:** funding start + full repair. Same 10% later if a lender funds them. Cash.  
**Fail:** “repair will raise your score so funding will work.”

### D5 — Full repair $1,000

Not a usual cash funding buyer. They want file work.  
**Right lane:** repair **$1,000**, cash.  
**Fail:** finance the repair; score-up promise.

### D6 — Repair trial $200

They want to see how we work, one round.  
**Right lane:** trial **$200**, cash.  
**Fail:** “this one round will clear the file.”

### D7 — UnderwriteIQ course (financeable)

About **500+**, not a $3,000 cash funding buyer.  
**Right lane:** UnderwriteIQ pack, listed **$1,000**, can go up to **$5,000**. **May finance** if they qualify (~500+, about 12–24 months, ~20% is owner-said not a locked APR on the call).  
**Must:** a course is school, not us getting them funded.  
**Fail:** “not sure” on score and you still finance; sell this as done-for-you funding.

### D8 — Funding Mastery course (financeable)

Same buyer type as D7, bigger map.  
**Right lane:** Funding Mastery **$5,000**. **May finance** if they qualify.  
**Fail:** same as D7.

### D9 — Cash downsell (under 500 or “not sure”)

**Right lane:** $32 and/or $200 and/or $1,000 cash. Do not force $3,000. Do not invent a cash payment plan.  
**Fail:** finance when they said “not sure.”

### D10 — Mad later / denied

They already paid in the story, a lender said no later.  
**Must:** listen. Do not argue. Name the next step and a time. Get a manager if you want to invent a fix.  
**Fail:** a new fund promise; a score promise.
