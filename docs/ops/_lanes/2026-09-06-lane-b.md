**A trap inside that file, for anyone who adds a thirteenth rule.** Lines 235-243 warn
that every stored pattern is compiled **twice** - once by Postgres when the row is saved,
and once by JavaScript when copy is screened. The two spell word boundaries differently:
Postgres uses `\y` and reads `\b` as a backspace character; JavaScript uses `\b` and
reads `\y` as a plain letter y. A pattern using either one would save cleanly and then
**silently match nothing** in one of the two engines. So every pattern in the file is
written with explicit character classes instead, which mean the same thing in both. Do
not add a rule using `\b` or `\y`.

### 1e. The exact file shape a generator agent must match

**`docs/ads/registry.json`** - keyed as a **list, not an object**. Top-level keys are
`version`, `updated`, `source`, `vocabulary`, `rules`, `ads`. `ads` is an array of 24
entries; you find an ad by scanning for its `id`, which is a **string of digits**, not
a number.

The 24 ids present: 16, 26, 27, 28, 29, 30, 31, 42, 43, 44, 45, 46, 72, 73, 74, 75, 76,
77, 78, 79, 80, 81, 82, 83.

Every entry has these **eight** fields, plus an optional ninth, `group`, that only
appears on some. Here are the first two entries in the file, copied exactly as they are
stored:

```json
[
 { "id": "16", "title": "phase", "lane": "funding600", "gate": "600",
   "entry": "direct", "primary_offer": "funding_dfy", "secondary_offers": [],
   "variants": ["sun", "nosun"] },
 { "id": "26", "title": "underwriter", "lane": "uwiq", "gate": "none",
   "entry": "sorting", "primary_offer": "capital_blueprint", "secondary_offers": "all",
   "variants": ["sun", "nosun"] }
]
```

Neither of the first two carries a `group`. One that does looks like this - ad 42:

```json
{ "id": "42", "title": "ringlights", "lane": "funding600", "gate": "600",
  "entry": "direct", "primary_offer": "funding_dfy", "secondary_offers": [],
  "variants": ["sun", "nosun"], "group": "slam" }
```

The exact allowed strings, from the `vocabulary` block:

- `lane` - `funding600` · `premium` · `sorting` · `uwiq` · `wl`
- `gate` - `600` · `720` · `780` · `none`
- `entry` - `direct` · `sorting`
- `offer` - `funding_dfy` · `credit_optimization` · `capital_blueprint` ·
  `capital_academy` · `white_label` · `none`
- `variant` - `sun` · `nosun` · `sedona`
